# Dodanie FV 

Dodanie nowej fv rozpoczynamy poprzez przejście w BOHu na zakładkę: **Faktury** <kbd> → </kbd> **Lista_faktur**

Na liście sal należy kliknąć przycisk <button class="btn-id"> Dodaj fakturę <span class="button-icon"> + </span> </button>
